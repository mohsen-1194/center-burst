### Write a program in Python that does the following instructions:

#### In a square page of size 800 * 800 pixel and in a loop with 50 iteration:

- draw a point in the center of the page.
- then choose a random point near the first point and draw a line between the two points.
- repeat the second step until you reach the border of the page. You must write the algorithm in a way that with every point you choose, you get far from the center.
- in the end you must reach a shape that connect the center of the page to the border of the page with 50 random path.
